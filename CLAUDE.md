# soonhokong.github.io

Personal academic webpage for Soonho Kong, hosted at https://soonhokong.github.io.

## Building

Run `make` from the repository root to build the site. Targets:

- `make` (default `all`): builds `index.html`, `cv.pdf`, `lean/index.html`.
- `make publications.html`: regenerates publications HTML from `publications.bib`.
- `make patents.html`: regenerates patents HTML from `patents.bib`.
- `make clean`: `git clean -fxd` (removes all untracked files).

### Required tools

- `bibtex2html` (Homebrew: `bibtex2html`)
- `multimarkdown` (Homebrew: `multimarkdown`)
- `html-minifier` (npm: `html-minifier`)
- `uglifycss` (npm: `uglifycss`) — only needed when `css/tufte.css` changes
- `latexmk` + `xelatex` — only needed for `cv.pdf`

## Source vs. generated files

**Edit these (sources):**

- `index.md` — main page content (markdown).
- `publications.bib` — publications list (BibTeX).
- `patents.bib` — patents list (BibTeX).
- `lean/index.md` — Lean subpage content.
- `cv.tex` — CV source.
- `css/tufte.css` — stylesheet source.
- `dsgplain.bst` — BibTeX style.
- `Makefile`

**Do NOT edit these (auto-generated by `make` — your changes will be overwritten):**

- `index.html` — generated from `index.md` (which inlines `publications.html` and `patents.html`).
- `publications.html`, `publications_bib.html` — generated from `publications.bib`.
- `patents.html`, `patents_bib.html` — generated from `patents.bib`.
- `lean/index.html` — generated from `lean/index.md`.
- `css/tufte.min.css` — generated from `css/tufte.css`.
- `cv.pdf` — generated from `cv.tex` (via `build/cv.pdf`).

## Workflow for adding a publication

1. Add the BibTeX entry to `publications.bib` (most recent at top).
2. Run `make publications.html` to regenerate publication pages.
3. Run `make index.html` to refresh the inlined publications on the homepage.
4. Commit both the source `.bib` change and the regenerated HTML.
